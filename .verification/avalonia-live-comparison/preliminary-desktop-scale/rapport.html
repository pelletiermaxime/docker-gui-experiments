What differs from MAUI?

Both C# ports use the same .NET SDK and Docker.DotNet.Enhanced 4.3.3 client, equivalent background request/timeout logic, the same four fields, last-good-state behavior and post-decode 20,000-row cap. Avalonia uses its normal desktop integration and Skia rendering; MAUI's observed Linux host is an experimental GTK4 backend. Avalonia's default renderer/adapter is not forced. Loaded graphics libraries are recorded, but library presence does not independently identify the active GPU.

Runtime and toolkit differences, JIT behavior, caches, selected features and unequal sample durations prevent assigning every difference to a single cause. MAUI has three longer final runs; Avalonia has one short run. This is an exploratory comparison, not a controlled language or renderer ranking.

Code and portability

A small code-only UI uses Avalonia's DataGrid and text input rather than custom controls. No MVVM framework or bundled font set is added. Requests cannot overlap and window closure cancels the active load. The SDK buffers its full response before the retention limit, so this is not a common wire-byte cap.

Avalonia supports Windows, macOS and Linux upstream. Only this Linux X11/XWayland run is observed; Windows/macOS builds and named-pipe/TLS transports are not proven here. DOCKER_HOST explicitly selects the endpoint, or the app uses its local platform default.
